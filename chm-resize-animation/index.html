深色格 = 已搬完（老表槽位已插 ForwardingNode）　浅色格 = 已认领但未搬完　灰色 = 无人认领　方框 = 该线程当前正在搬的桶
四条必须讲清的边界：
1. 发起者没有特权：只多做「建 nextTable（:2431）+ 置 transferIndex = n（:2438）」两件事，之后和所有人一样靠 CAS 抢段。
2. 搬完一段不退出：外层 for (;;)（:2444）+ 内层 while (advance)（:2446）回头再抢，所以段数不必等于线程数（3 线程搬 4 段）。
3. 来晚的线程不空转：transferIndex <= 0 时 helpTransfer（:2371）/ addCount（:2348）直接 break；帮手上限 MAX_RESIZERS = 65535（:581）。
4. 收尾只由最后一人做（:2471-2473），且需 i = n 全表复查（:2475）后才提交新表。
反直觉点：stride = max((n>>>3)/NCPU, 16)（:2426-2427），表长 16 时整表只有 1 段，第二个线程根本没段可抢——「并肩搬」至少要表长 ≥ 32。
